# தமிழ் எழுத்து மற்றும் இலக்கியக் குறிப்பு
## Tamil Writing & Literary Reference

Shared reference for all Tamil commands. Individual commands reference this for grammar, word replacements, and literary principles.

---

## 1. சந்திப் பிழைகள் (Sandhi Rules)

### வல்லினம் மிகும் இடங்கள்
- இரண்டாம் வேற்றுமை உருபு விரிவில்: "வீட்டைக் கட்டினான்" (க் மிகும்)
- சுட்டெழுத்து முன்: "அக்கரை", "இக்கரை"
- வினையெச்சம் + வினை: "படித்துக் கொண்டான்"
- "எ" சாரியை பெற்ற சொற்கள் முன்: "நன்றிக்கு உரியவன்"

### வல்லினம் மிகா இடங்கள்
- இரண்டாம் வேற்றுமை விரி அல்லாத இடங்கள்: "படித்த பையன்" (ப் மிகாது)
- உவமை உருபு "போல்" முன்: "மலர் போல" (ல் மிகாது)
- வினையடை முன்: "மெல்ல சென்றான்"
- "உம்" சாரியை சேர்ந்த சொற்கள் முன் பலவற்றில் மிகாது

### இயபு விகாரம் (Ya-Transformation)
- ❌ பிறரை பார்த்தார் → ✅ பிறரைப் பார்த்தார்

### மெய் விகாரம் (Consonant Elision)
- ❌ கண்ணாடி சிகரம் → ✅ கண்ணாடிச் சிகரம்

### அடிக்கடி காணப்படும் தவறுகள்
- "படித்தப் பையன்" → "படித்த பையன்" (வல்லினம் தேவையில்லை)
- "வந்தது கண்டான்" → "வந்ததைக் கண்டான்"
- "தமிழ் கற்றான்" → "தமிழைக் கற்றான்" (இரண்டாம் வேற்றுமை)
- "தமிழ் தூண்டுவினா" → "தமிழ்த் தூண்டுவினா" (வல்லினம் மிகும்)
- "நிகழ்வு பொறுத்தம்" → "நிகழ்வுப் பொறுத்தம்" (வல்லினம் மிகும்)

## 2. வாக்கிய அமைப்பு (Sentence Structure)

- தமிழ் வாக்கிய வரிசை: **எழுவாய் → செயப்படுபொருள் → பயனிலை**
  - சரி: "கண்ணன் பந்தை எறிந்தான்"
  - பிழை: "கண்ணன் எறிந்தான் பந்தை"
- நீண்ட வாக்கியங்களை இரண்டாகப் பிரி
- ஒரு வாக்கியத்தில் ஒரே கருத்து மட்டுமே

---

## 3. வேற்றுமை உருபுகள் (Case Markers)

| வேற்றுமை | உருபு | உதாரணம் |
|-----------|-------|----------|
| முதல் | (உருபில்லை) | கண்ணன் வந்தான் |
| இரண்டாம் | ஐ | மரத்தை வெட்டினான் |
| மூன்றாம் | ஆல், ஆன் | கையால் செய்தான் |
| நான்காம் | கு | அவனுக்குக் கொடு |
| ஐந்தாம் | இல், இலிருந்து | ஊரிலிருந்து வந்தான் |
| ஆறாம் | அது, இன் | அவனது வீடு |
| ஏழாம் | கண், இல் | வீட்டில் இருக்கிறான் |

## 4. பால் / எண் வினைமுற்று

- "அவன் சென்றான்" / "அவள் சென்றாள்" / "அது சென்றது" — கலைக்காமல் பேணு
- மரியாதைப் பன்மை: "அவர்கள் சென்றார்கள்" — வினைமுற்று பன்மையாக இருக்கட்டும்

| Drone | ட்ரோன் | வானூர்தி |
| Economy | எகனாமி | பொருளாதாரம் |
| Education | எஜுகேஷன் | கல்வி |

## 7. வடமொழி → தூய தமிழ்

செந்தமிழ் நடையில் எழுதும்போது மாற்று. மரபாக வழங்கும் கலைச்சொற்களை (யாப்பிலக்கணம் போன்றவை) மாற்ற வேண்டாம்.

| வடமொழி சார்பு | தூய தமிழ் |
|--------------|-----------|
| சாஸ்திரம் | நூல் / கலை |
| பிரம்மாண்டம் | மாபெரும் |
| பவித்திரம் | தூய்மை |
| ஆசீர்வாதம் | வாழ்த்து |
| விஷயம் | செய்தி / கருத்து |
| சந்தேகம் | ஐயம் |
| நிச்சயம் | உறுதி |
| உத்தியோகம் | பணி |
| ஆலயம் | கோயில் |
| வித்தியாசம் | வேறுபாடு |

## 9. கட்டுரை நடை வகைகள்

| வகை | நடை |
|-----|------|
| வரலாற்றுக் கட்டுரை | தெளிவான, நிதானமான, ஆவண நடை |
| இலக்கியக் கட்டுரை | அலங்கார நடை, மேற்கோள்கள் அதிகம் |
| அறிவியல் / தொழில்நுட்பம் | எளிய, நேரடி நடை; கலைச்சொற்கள் விளக்கத்துடன் |
| சமூக விவாதம் | வலுவான நிலைப்பாடு, ஆதாரங்களுடன் |
| பயணக் கட்டுரை | விவரண நடை, இயற்கை வர்ணனை |
| செய்தி | சுருக்கமான, செயல்நிலை வினை, தலைகீழ் பிரமிடு |

## 10. யாப்பு / ஓசை (Prosody)

| கலைச்சொல் | விளக்கம் |
|-----------|---------|
| மோனை (Monai) | முதல் எழுத்து ஒன்றுபோல் வருதல் — alliteration |
| எதுகை (Edugai) | இரண்டாம் எழுத்து ஒன்றுபோல் வருதல் — rhyme |
| சந்தம் (Sandham) | ஒலி நயமான தாள ஓட்டம் — rhythm |
| இயைபு (Iyaibu) | கடைசி எழுத்து ஒன்றுபோல் வருதல் — end rhyme |

மேடைக் கவிதை மற்றும் செய்யுள் நடையில் மோனை/எதுகை பயன்படுத்துவது வாசகர்/கேட்போர் ஈடுபாட்டை அதிகரிக்கும்.

## 11. புதுக்கவிதை கொள்கைகள் (Modern Poetry Principles)

| கொள்கை | விளக்கம் |
|--------|---------|
| **சொற் சிக்கனம்** | குறைவான சொற்களில் ஆழமான பொருள்; ஒரு சொல்லை நீக்கினால் பொருளே சிதையும் |
| **காட்சிப் படிமம்** | சொல்வதை விட காட்டு (Show, don't tell); உணர்வை காட்சியாக நிறுத்து |
| **பூடகத் தன்மை** | எல்லாவற்றையும் வெளிப்படையாகச் சொல்லாதே; வாசகனுக்கு இடைவெளி விடு |
| **புதுமையான பார்வை** | பழைய கருவையும் புதிய கோணத்தில் பார் |
| **உள்ளோசை** | யாப்பு இல்லாவிட்டாலும் வரிகளில் நதி போன்ற ஓட்டம் வேண்டும் |
| **சமூக அக்கறை / உண்மை** | சமூக வலி அல்லது கவிஞனின் உண்மையான உணர்வு பிரதிபலிக்க வேண்டும் |

## 12. கவிதை / இலக்கிய மதிப்பீட்டு அளவுகோல்கள்

| அளவுகோல் | என்ன பார்க்க வேண்டும் |
|-----------|---------------------|
| **மொழிநடை** | சொல் தேர்வு துல்லியம், உவமை/உருவக வலிமை |
| **உணர்ச்சி வெளிப்பாடு** | உணர்வு நேரடியாகச் சொல்லாமல் கடத்தப்படுகிறதா |
| **அமைப்பு / தாளம்** | உள்ளோசை, வரி உடைப்பு அர்த்தமுள்ளதா |
| **தலைப்பு / முடிவு** | தலைப்பு பொருத்தம், முடிவு சிந்திக்க வைக்கிறதா |
| **படிமம் / காட்சி** | concrete imagery vs abstract statements |
| **புதுமை** | நவீனத்துவம், cliche தவிர்ப்பு |
